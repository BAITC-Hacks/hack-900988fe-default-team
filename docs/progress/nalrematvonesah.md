### 2026-09-23 — первый рабочий блок backend MVP

- Реализованы Node.js HTTP-каркас, API по существующему контракту, in-memory модели задач/команд/откликов и пять синтетических seed-записей каждого типа.
- Добавлен scoring 0–100 по семи категориям; начисление только непустому подтверждённому полю; рекомендации по недостающим сведениям.
- Добавлены анализ черновика с OpenAI Responses JSON Schema Structured Output и локальный fallback, compose карточки, CRUD задач, публикация, каталог и ручные статусы откликов.
- Изменены: `backend/package.json`, `backend/src/*`, `backend/test/scoring.test.js`, `backend/README.md`, `backend/.env.example`.
- Проверки: `node --test` — 2/2 прошли; smoke check `GET /api/health` вернул `{"status":"ok"}`, `GET /api/tasks` вернул 5 seed-задач.
- Известное ограничение: хранилище in-memory, поэтому записи теряются при перезапуске; `DATABASE_URL` пока резерв для подключения постоянной БД.
- Следующий шаг: проверить API smoke-сценарием, корректность ответа OpenAI с реальным настроенным ключом и согласовать поле связи с бизнесом.

### 2026-09-23 — проверка интеграционного сценария

- Fallback теперь заполняет `title` исходным текстом черновика, не добавляя нового факта. Создание и обновление задач проверяют список допустимых подтверждённых полей.
- Проверка `node --test`: 3/3 passed, включая границы 40/70/90 и fallback-заголовок.
- Сквозной HTTP smoke на порту 3001 прошёл: analyze (3 вопроса и title) → create task (100 баллов) → publish → proposal → ручной статус `selected`.
- Во frontend сейчас есть только `mockAdapter`; вызов API и переключение по `VITE_API_BASE_URL` пока не подключены. Это за пределами backend-зоны, требуется интеграция владельцем frontend.
- Ограничения прежние: in-memory данные сбрасываются при рестарте; OpenAI вызов не проверялся, так как ключ не настроен.

### 2026-09-23 — SQLite-хранилище

- Заменено JSON-хранилище на SQLite в пути из `DATABASE_URL` (`file:./dev.db` по умолчанию). При первом запуске создаются таблицы `tasks`, `teams`, `proposals` и seed. Сохранённые задачи и отклики переживают перезапуск.
- При восстановлении рейтинг пересчитывается по сохранённым полям и подтверждениям, поэтому результат не зависит от устаревших сохранённых баллов. Существующий JSON-файл старой версии автоматически переносится в SQLite, а исходник сохраняется как `.json.bak`.
- Изменены: `backend/src/store.js`, `backend/package.json`, `backend/README.md`.
- Проверки: `node --test` — 3/3 passed. Smoke: сервер на временной SQLite-базе вернул 5 seed-задач; прямой SQL-запрос `SELECT count(*) FROM tasks` вернул 5. Тестовая БД удалена после проверки.
- Ограничение: используется встроенный экспериментальный `node:sqlite`, поэтому минимальная версия runtime — Node.js 22. Одновременная запись несколькими процессами не является поддерживаемым сценарием MVP.

### 2026-09-23 — Swagger API-документация

- Добавлены OpenAPI 3.0.3-спецификация и Swagger UI с описанием всех контрактных endpoint-ов, параметров, схем ответов и ошибок.

- Изменены: `backend/src/openapi.js`, `backend/src/server.js`, `backend/package.json`, `backend/package-lock.json`, `backend/README.md`.

До согласования поле поддерживается backend в `fields`, но AI-схема его не извлекает.
