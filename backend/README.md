# Backend HackAlem AI

Backend MVP на Node.js 20+ без внешних runtime-зависимостей. API использует JSON и префикс `/api`; маршруты согласованы с корневым `API_CONTRACT.md`.

## Запуск

```powershell
cd backend
Copy-Item .env.example .env
npm run dev
```

Для обычного запуска используйте `npm start`. По умолчанию сервер слушает порт `3000`, frontend разрешён на `http://localhost:5173`.

Переменные окружения: `PORT`, `DATABASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL`, `FRONTEND_ORIGIN`. Ключ OpenAI необязателен: без него анализ возвращает fallback. Не добавляйте `.env` в репозиторий.

## API и сценарий

Реализованы health check, анализ черновика, формирование карточки, создание/редактирование/публикация задачи, каталог с `theme`, `level`, `sort`, создание/просмотр откликов и ручное изменение статуса (`pending`, `selected`, `rejected`). Низкий рейтинг не мешает публикации; выбор команды не выполняется автоматически. Ошибки имеют контрактный вид `{ "error": { "code", "message", "details" } }`.

Рейтинг детерминированный, диапазон 0–100. Баллы начисляются только за непустые поля, перечисленные в `confirmedFields`. AI вызывается через OpenAI Responses API с JSON Schema Structured Output; при отсутствии ключа, ошибке API или неверном ответе используются fallback-вопросы. Извлечённые данные ограничены схемой, а системная инструкция запрещает выводить неподтверждённые факты.

## Данные

Пока используется in-memory хранилище: пять синтетических задач, пять команд и пять откликов создаются при старте. Данные и созданные записи сбрасываются при перезапуске. `DATABASE_URL` оставлен для следующего этапа подключения постоянной БД; миграции пока не требуются.

## Проверки

```powershell
npm test
```

Тесты проверяют начисление баллов по подтверждённым полям и уровни рейтинга.

## Структура

- `src/server.js` — HTTP-маршруты, валидация и единый формат ошибок;
- `src/scoring.js` — детерминированный рейтинг;
- `src/ai.js` — Structured Output и fallback;
- `src/store.js` — модели в памяти и demo seed;
- `test/scoring.test.js` — тесты scoring service.
