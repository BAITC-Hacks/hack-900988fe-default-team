# Backend HackAlem AI

Backend MVP на Node.js 22+ без внешних runtime-зависимостей. SQLite предоставляется встроенным модулем Node.js. API использует JSON и префикс `/api`; маршруты согласованы с корневым `API_CONTRACT.md`.

## Запуск

```powershell
cd backend
Copy-Item .env.example .env
npm run dev
```

Для обычного запуска используйте `npm start`. По умолчанию сервер слушает порт `3000`, frontend разрешён на `http://localhost:5173`.

Переменные окружения: `PORT`, `DATABASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL`, `FRONTEND_ORIGIN`, `API_BASE_URL`. Ключ OpenAI необязателен: без него анализ возвращает fallback. `API_BASE_URL` задаёт первый вариант сервера в Swagger, например `https://api.example.com/api`. Не добавляйте `.env` в репозиторий.

## API и сценарий

Реализованы health check, анализ черновика, формирование карточки, создание/редактирование/публикация задачи, каталог с `theme`, `level`, `sort`, создание/просмотр откликов и ручное изменение статуса (`pending`, `selected`, `rejected`). Низкий рейтинг не мешает публикации; выбор команды не выполняется автоматически. Ошибки имеют контрактный вид `{ "error": { "code", "message", "details" } }`.

Валидация проверяет JSON-тела, подтверждённые поля, ответы AI-конструктора, статусы, параметры каталога и HTTP(S)-ссылку на прототип.

После запуска Swagger UI доступен по адресу `http://localhost:3000/api/docs`, а исходная OpenAPI-спецификация — по `http://localhost:3000/api/openapi.json`.

Рейтинг детерминированный, диапазон 0–100. Баллы начисляются только за непустые поля, перечисленные в `confirmedFields`. AI вызывается через OpenAI Responses API с JSON Schema Structured Output; при отсутствии ключа, ошибке API или неверном ответе используются fallback-вопросы. Backend принимает AI-поле только когда его текст подтверждён исходным черновиком; неподтверждённые значения очищаются и заменяются уточняющими вопросами.

## Данные

Используется SQLite, путь к базе задаёт `DATABASE_URL` в формате `file:./dev.db`. При первом запуске создаются таблицы `tasks`, `teams`, `proposals` и пять синтетических задач, команд и откликов. Изменения задач и откликов сохраняются между перезапусками. Если нужен чистый demo seed, остановите сервер и удалите только файл `backend/dev.db`.

## Проверки

```powershell
npm test
```

Тесты проверяют начисление баллов по подтверждённым полям, уровни рейтинга, защиту от неподтверждённых AI-фактов и полный HTTP-сценарий с изолированной SQLite-базой.

## Структура

- `src/server.js` — HTTP-маршруты, валидация и единый формат ошибок;
- `src/scoring.js` — детерминированный рейтинг;
- `src/ai.js` — Structured Output и fallback;
- `src/store.js` — модели в памяти и demo seed;
- `test/scoring.test.js` — тесты scoring service.
