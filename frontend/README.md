# Frontend

## Требования

Заполнить фактические версии Node.js и пакетного менеджера.

## Настройка

```bash
cp .env.example .env
```

## Разработка

Добавить фактические команды после инициализации frontend.

## Сборка и проверки

Добавить команды build, lint и test, которые реально существуют.

## Переменные окружения

Документировать каждую переменную из `.env.example` без секретов.

## Структура

Кратко описать страницы, UI-компоненты, API adapter и состояние приложения.
